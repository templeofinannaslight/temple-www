1. About RecoverySky

RecoverySky is a mobile application designed to help individuals in addiction recovery find and join online recovery meetings. The app aggregates meeting schedules from multiple recovery fellowships (AA, NA, CMA, Recovery Dharma) and provides a streamlined interface for discovering live meetings and joining them instantly via Zoom.

Purpose

  • Simplify the process of finding online recovery meetings
  • Enable immediate participation in live meetings with one tap
  • Support multiple recovery pathways (12 Step and Buddhist-inspired)
  • Provide optional attendance documentation for court-ordered requirements

Target Users

Individuals seeking recovery from drug and alcohol addiction who want to attend online fellowship meetings.

2. Integration Type & Architecture

Integration Type

Zoom Meeting SDK (Embedded)

RecoverySky uses the Zoom Meeting SDK to embed Zoom meeting functionality directly within the native mobile application. This is not an OAuth-based integration.

Architecture Overview

Component Description
Client Application Native mobile app (iOS/Android) with embedded Zoom Meeting SDK
Meeting Data RecoverySky backend provides meeting IDs and passwords for public recovery meetings
Zoom Integration Meeting SDK joins meetings as a guest participant (no host privileges)

Authorization Flow

No end-user Zoom authorization is required.

The Zoom Meeting SDK uses JWT authentication at the application level. End users:

  • Do NOT need a Zoom account
  • Do NOT authorize any Zoom permissions
  • Do NOT connect their Zoom account to RecoverySky
  • Join meetings as anonymous guest participants

This design is intentional to protect the anonymity of recovery meeting participants.

3. Scopes & Permissions

Zoom Scopes

None. The Zoom Meeting SDK does not use OAuth scopes. The SDK is authenticated via JWT/SDK credentials at the application level, not the user level.

What RecoverySky Can Do

Capability Description
Join Meetings Join existing Zoom meetings as a participant using meeting ID and password
Set Display Name Set the user's display name when joining a meeting
Audio/Video Controls Mute/unmute microphone, enable/disable camera during meetings
Leave Meeting Exit from an active meeting

What RecoverySky Cannot Do

  • Access user's Zoom account or profile
  • Host or schedule meetings
  • Access meeting recordings
  • View participant lists from Zoom
  • Access any Zoom account data
  • Modify any Zoom settings

Device Permissions Required

Permission Purpose Required?
Microphone Audio participation in meetings Yes (for audio participation)
Camera Video participation in meetings Optional
Internet Fetch meeting data and connect to Zoom Yes

We have obsrved the first attempt to join a meeting from within TestFlight may not allow the use of video in the meeting.

This is a Zoom React SDK issue within TestFligh and not an issue with the RecoverySky app. Exiting and rejoining the meeting allows proper video, or if when running RecoverySky outside of TestFlight video alwasy works correctly.

7. Step-by-Step Test Plan

Test Case 1: App Launch & Anonymous Login

Step Action Expected Result
1.1 Launch RecoverySky app App opens to login/welcome screen
1.2 Tap "Anonymous" button User proceeds without creating an account
1.3 On onboarding screen, tap "Skip for now" User bypasses onboarding and enters main app
1.4 Observe main screen App displays navigation options including Meetings tab

Test Case 2: View Live Meetings

Step Action Expected Result
2.1 Tap "Go to Live" or select the Meetings tab App displays list of currently live recovery meetings
2.2 Observe meeting list Each meeting shows: meeting name, fellowship type (AA/NA/CMA/RD), and live status
2.3 Wait or manually refresh Meeting list updates (auto-refreshes every 15 minutes)

Test Case 3: View Meeting Details

Step Action Expected Result
3.1 Tap on any live meeting in the list Meeting detail popup/screen appears
3.2 Review meeting details Details include meeting name, fellowship, description, and "Join Meeting" button
3.3 Tap outside popup or back button Returns to meeting list

Test Case 4: Set Display Name

Step Action Expected Result
4.1 Tap on Settings in lower right of application View Application Settings
4.1 Locate the Short Name input field Input field is visible
4.2 Enter a display short name (e.g., "Reviewer Z.") Name is saved and will be used when joining meetings

Test Case 5: Join a Zoom Meeting

Step Action Expected Result
5.1 Tap on a live meeting to open details Meeting detail popup appears with "Join Meeting" button
5.2 Tap "Join Meeting" button App requests video/microphone permission (if not already granted)
5.3 Grant video/microphone permission Zoom requests meeting password
5.4 Enter meeting password: "test" Zoom accepts the password
5.5 Wait for connection User joins the Zoom meeting with their configured display name
5.6 Observe Zoom meeting interface Standard Zoom meeting controls are available (mute, video, leave)

Test Case 6: Leave Meeting

Step Action Expected Result
6.1 While in a meeting, tap "Leave" or the end call button Confirmation prompt appears (or user exits directly)
6.2 Confirm leaving the meeting User exits Zoom meeting and returns to RecoverySky app
6.3 Observe app state App returns to meeting list, ready to join another meeting
